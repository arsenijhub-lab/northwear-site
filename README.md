# NORTH WEAR

## Открыть сайт на компьютере

Дважды щёлкните `start-site.bat` или откройте `index.html` в браузере. Для просмотра фотографий нужен интернет.

Файл `catalog.js` с исходным архивом должен находиться рядом с `index.html`.

## Кабинет сотрудников, товары и заказы

Кабинет сотрудников находится в [`staff.html`](./staff.html). После подключения Supabase сотрудники смогут управлять товарами, фотографиями и остатками, а также просматривать заказы и менять их статусы с разных устройств.

Для запуска кабинета в интернете:

1. Создайте проект Supabase и сохраните Project URL и **публичный anon/publishable key** в `supabase-config.js`. Никогда не помещайте service-role key или пароль базы данных в HTML, JavaScript или общедоступный репозиторий.
2. Откройте SQL Editor проекта и выполните содержимое `supabase-setup.sql`.
3. В Supabase Auth оставьте разрешёнными только вход по паролю и подтверждение электронной почты. Отключите публичную ссылку регистрации, включите подтверждение адреса и не включайте автоматическое создание пользователей в кабинете.
4. Опубликуйте файлы магазина на HTTPS-хостинге. Статические HTML-страницы нельзя распространять как `file://`, если кабинет должен отправлять заказ в базу.
5. **До создания первой учётной записи** в Supabase SQL Editor добавьте одно одноразовое приглашение владельца. Подставьте свою настоящую рабочую почту:

   ```sql
   INSERT INTO public.staff_invites (email, role)
   VALUES (lower('ВАША_РАБОЧАЯ_ПОЧТА'), 'admin')
   ON CONFLICT (email) DO UPDATE SET role = 'admin';
   ```

6. Откройте `staff.html` по опубликованному адресу, зарегистрируйте владельца на приглашённую рабочую почту и подтвердите адрес электронной почты. Первая учётная запись автоматически получит роль администратора.
7. Войдите в кабинет администратора, выберите «Працівники» и добавьте рабочие адреса сотрудников. Каждый сотрудник сам задаёт пароль по приглашению. Для восстановления пароля используйте панель Supabase Auth.
8. Перед загрузкой каталога проверьте цены и наличие. Затем в кабинете выберите «Імпортувати каталог» и укажите `catalog-seed.json`. Файл содержит начальные данные, собранные из сайта и архива: существующие товары с таким же ID будут обновлены.
9. Проверьте зарегистрированный заказ и статусы с двух отдельных учётных записей.

### Возможности кабинета

- Добавление и редактирование товаров, цен, размеров, подписей, тегов и наличия.
- Загрузка фотографий JPEG, PNG или WebP до 8 МБ.
- Архивирование без окончательного удаления товара.
- Просмотр заявок магазина и статусы «Нове», «В роботі», «Завершене», «Скасоване».
- Ограниченные приглашения сотрудников и разделение ролей «адміністратор» / «працівник».
- Безопасность данных обеспечивают политики доступа RLS в `supabase-setup.sql`.
- Избранное сохраняется в браузере покупателя; заказ ограничен 25 позициями и 99 единицами одного товара одного размера.

### Заказы и цены

После подключения Supabase заказы сохраняются в общей базе до перехода в Telegram. Итог и стоимость рассчитываются на сервере из актуальных цен каталога; наличие проверяется по учтённому остатку. При неизвестном остатке товар доступен для заказа, но наличие подтверждает менеджер.

Если Supabase уже настроен, после обновления `supabase-setup.sql` выполните его в SQL Editor ещё раз, чтобы применить серверное ограничение количества.

У четырёх товаров архивного каталога цена не указана — она показывается как «Ціну уточнити» и добавить такие позиции в корзину нельзя. До запуска подтвердите цены и наличие у менеджера.
