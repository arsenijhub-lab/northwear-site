# NORTH WEAR

## Открыть сайт на компьютере

Дважды щёлкните `start-site.bat`. Скрипт запустит локальный HTTP-сервер только на этом компьютере и откроет сайт в браузере. Нажмите Ctrl+C в окне сервера, чтобы остановить его. Для просмотра фотографий нужен интернет.

Файл `catalog.js` с исходным архивом должен находиться рядом с `index.html`.

Локальный запуск позволяет проверить интерфейс. Отправка заказов и индивидуальных заявок, вход в кабинет и хранение общих данных работают только после подключения Supabase в `supabase-config.js`.

## Кабинет сотрудников, товары и заказы

Кабинет сотрудников находится в [`staff.html`](./staff.html). После подключения Supabase сотрудники смогут управлять товарами, фотографиями и остатками, а также просматривать заказы и менять их статусы с разных устройств. Используйте один и тот же опубликованный адрес `staff.html`: после первого входа Supabase сохраняет сессию в браузере, поэтому при следующих посещениях на этом устройстве вход обычно не требуется. Ссылка открывает страницу входа, но сама по себе не даёт доступ к кабинету — для доступа нужна приглашённая учётная запись.

Для запуска кабинета в интернете:

1. Создайте проект Supabase и сохраните Project URL и **публичный anon/publishable key** в `supabase-config.js`. Никогда не помещайте service-role key или пароль базы данных в HTML, JavaScript или общедоступный репозиторий.
2. Откройте SQL Editor проекта и выполните содержимое `supabase-setup.sql`.
3. В Supabase Auth включите регистрацию по электронной почте и парольный вход с подтверждением адреса. Не публикуйте открытую ссылку регистрации: в кабинете регистрацию можно завершить только с приглашённой почтой, а триггер базы отклоняет остальные адреса. Не включайте автоматическое создание пользователей в кабинете.
4. Опубликуйте файлы магазина на HTTPS-хостинге. Статические HTML-страницы нельзя распространять как `file://`, если кабинет должен отправлять заказ в базу.
5. **До создания первой учётной записи** в Supabase SQL Editor добавьте одно одноразовое приглашение владельца. Подставьте свою настоящую рабочую почту:

   ```sql
   INSERT INTO public.staff_invites (email, role)
   VALUES (lower('ВАША_РАБОЧАЯ_ПОЧТА'), 'admin')
   ON CONFLICT (email) DO UPDATE SET role = 'admin';
   ```

6. Откройте `staff.html` по опубликованному адресу, зарегистрируйте владельца на приглашённую рабочую почту и подтвердите адрес электронной почты. Первая учётная запись автоматически получит роль администратора. После входа браузер запомнит сессию; она может завершиться после выхода, очистки данных браузера, отзыва доступа или истечения срока действия сессии.
7. Войдите в кабинет администратора, выберите «Працівники» и добавьте рабочие адреса сотрудников, которым действительно нужен доступ к управлению магазином. Каждый сотрудник сам задаёт пароль по приглашению. Для восстановления пароля используйте панель Supabase Auth.
8. Перед загрузкой каталога проверьте цены и наличие. Затем в кабинете выберите «Імпортувати каталог» и укажите `catalog-seed.json`. Файл содержит начальные данные, собранные из сайта и архива: существующие товары с таким же ID будут обновлены.
9. Проверьте зарегистрированный заказ, отмену с возвратом учтённого остатка и статусы с двух отдельных учётных записей.

### Автоматическая публикация на GitHub Pages

Файл `.github/workflows/pages.yml` собирает статический сайт и публикует его при каждом push в ветку `main`. Чтобы запустить публикацию, создайте или используйте собственный GitHub-репозиторий, загрузите в его корень файлы сайта вместе с `.github/workflows/pages.yml`, затем в настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**. Адрес опубликованного сайта появится в результате workflow. Для работы онлайн-заказов перед публикацией заполните URL проекта Supabase и публичный anon/publishable key в `supabase-config.js`; этот ключ предназначен для браузера, доступ к данным ограничивается RLS.

### Возможности кабинета

- Добавление и редактирование товаров, цен, размеров, подписей, тегов и наличия.
- Загрузка фотографий JPEG, PNG или WebP до 8 МБ.
- Архивирование без окончательного удаления товара.
- Просмотр заявок магазина и статусы «Нове», «В роботі», «Завершене», «Скасоване».
- Подборка «Хіт продажів» формируется по количеству заказанных товаров; отменённые заказы не учитываются.
- При отмене заказа учтённый остаток возвращается; повторное открытие отменённого заказа проверяет остаток и не допускает отрицательного значения.
- Ограниченные приглашения сотрудников и разделение ролей «адміністратор» / «працівник».
- Безопасность данных обеспечивают политики доступа RLS в `supabase-setup.sql`.
- Избранное сохраняется в браузере покупателя; заказ ограничен 25 позициями и 99 единицами одного товара одного размера.

### Заказы и цены

После подключения Supabase заказ создаётся в общей базе и сразу появляется в кабинете сотрудников — переходить в Telegram или подтверждать отправку сообщения не нужно. Итог и стоимость рассчитываются на сервере из актуальных цен каталога; наличие проверяется по учтённому остатку. При неизвестном остатке товар доступен для заказа, но наличие подтверждает сотрудник.

Для сохранения выбранного цвета, контактных данных и доставки, подсчёта хитов продаж, восстановления остатков при отмене заказа и приёма заявок на индивидуальный принт обновлённый `supabase-setup.sql` нужно выполнить в SQL Editor проекта ещё раз. Файл создаёт защищённое хранилище эскизов: покупатель отправляет заявку на сайте, а сотрудники видят её и изображение в разделе «Індивідуальні заявки». Хиты считаются по количеству единиц в заказах, кроме отменённых.

У четырёх товаров архивного каталога цена не указана — она показывается как «Ціну уточнити» и добавить такие позиции в корзину нельзя. До запуска подтвердите цены и наличие у менеджера.

## Публикация, домен и материалы

- При оформлении покупатель указывает имя, телефон, город и отделение/почтомат Новой почты. Заказ и данные доставки сохраняются в Supabase и доступны приглашённым сотрудникам в разделе «Замовлення» кабинета `staff.html`.
- Онлайн-оплата пока не подключена. Кнопка оплаты отключена и не списывает деньги. Для запуска понадобится зарегистрировать продавца в платёжном сервисе и подключить hosted checkout с серверным подтверждением платежа; данные банковских карт нельзя запрашивать или хранить на сайте. Сейчас в форме указана документация интернет-эквайринга Monobank.
- Ссылки на исходный Telegram-канал ведут на `@NORTHWEA`.
- До публикации каталога проверьте, что права на изображения и подписи разрешают их коммерческое использование.
- GitHub Actions публикует сайт только после загрузки файлов в существующий GitHub-репозиторий и включения GitHub Actions для Pages. У проекта также должна быть настроена база Supabase; без неё покупатель увидит уведомление, а отправка онлайн-заказов и заявок останется отключённой. Для работы с разных устройств нужен опубликованный HTTPS-адрес.
